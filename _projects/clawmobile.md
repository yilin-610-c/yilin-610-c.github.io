## Overview

ClawMobile explores reliable AI agents operating in real smartphone environments.

The project studies how agents can reduce unnecessary interaction cost through reusable capabilities, structured skills, and more efficient execution strategies.

## Research Focus

- Mobile agent reliability
- Token-efficient agent workflows
- Skill representation and reuse
- Real-world Android environments

## Outcome

Developed and evaluated approaches for improving agent efficiency beyond purely UI-based interaction.
