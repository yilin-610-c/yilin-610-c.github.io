## Overview

ClawMobile explores reliable AI agents operating in real smartphone environments.

The project studies how agents can reduce unnecessary interaction cost through reusable capabilities, structured skills, capability recipes, and more efficient execution strategies.

Advised by Prof. Chun Jason Xue and Prof. Youcheng Sun.

## Research Focus

- Mobile agent reliability
- Token-efficient agent workflows
- Reusable skills and capability recipes
- Reliable Android execution
- UI fallback for robust smartphone-native agents

## Outcome

Received the MBZUAI UGRIP 2026 Best Project Award for work on efficient and reliable mobile agent systems.
