**Final-year project · HKUST(GZ) · In progress**

## Research question

How can we systematically evaluate AI agents that develop quantization-related GPU kernels? These tasks bring together algorithmic choices, low-precision numerical computation, and hardware execution, so a useful evaluation needs to consider both numerical behavior and runtime performance.

## Current focus

I am investigating the scope and evaluation methodology of a quantization kernel agent benchmark. This project extends my work on quantization and efficient GPU computation toward agent-assisted systems development and reproducible evaluation.

Possible evaluation dimensions include:

- Functional correctness and numerical accuracy.
- Kernel performance and robustness across configurations.
- Reproducibility of agent-generated solutions.

These are research objectives under investigation, not completed benchmark components.

## Status

**Ongoing / In progress.** The title and scope are provisional. No benchmark release, publication, or evaluation results are being reported at this stage.
